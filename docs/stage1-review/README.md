# Stage 1 review: before and after

Screenshots from the Stage 0 visual harness (`npm run check:visual`: headless Chromium 141, software WebGL,
1600 x 900). `before-*` is the Stage 0 build (md5 `c09c4b23d9e245ff9d693960cf9496b9`); `after-*` is the Stage 1B build
(md5 `5bf48b75373fe0cf9fc8a32cbeae918c`). Same cases, same camera, same clock.

| view | what to look at |
|---|---|
| `first-run` | neutral accent; formation names neutral with a side mark; decision events as hollow diamonds in their side colour on the timeline; the first-run key unchanged |
| `overview-field` | the landscape theme: name labels, annotation text, the situation line and the timeline on the type scale |
| `staff-paper` | the whole interface in the paper theme; counters with cased side frames, nation tag, plated B/C badges and neutral status plates; the legend's badge row |
| `selected-formation` | the dossier's neutral status and claim pills with icons; the selection ring; text sizes and contrast in the rail and drawer |
